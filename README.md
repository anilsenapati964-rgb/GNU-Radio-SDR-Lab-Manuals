# GNU Radio SDR Lab Manuals

This repository contains laboratory experiments implemented using GNU Radio, PlutoSDR and RTL-SDR.

## Experiments

1. Doppler Effect using PlutoSDR
2. QPSK Transceiver
3. Sampling Theorem
4. OOK/ASK Communication
5. Pulse Shaping and Matched Filtering
6. Frequency Locked Loop (FLL)
7. Symbol Timing Recovery and Synchronization
8. Carrier Phase Synchronization using Costas Loop

## Hardware Used

- ADALM-PLUTO SDR
- RTL-SDR

## Software Used

- GNU Radio
- libiio
- PlutoSDR Drivers
